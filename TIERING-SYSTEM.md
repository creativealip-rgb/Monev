## 3. DETAILED TIER BREAKDOWN

### 🆓 TIER 1: STARTER (Free)

**Target:** New users, students, budget-conscious

**Price:** Rp 0/month

**Goal:** Let users experience core value, build habit

#### Features & Limits

| Feature | Limit | Rationale |
|---|---|---|
| **Transactions** | 100/month | Enough for 3-4 weeks, will hit limit |
| **Bank Accounts** | 2 accounts | Primary + e-wallet |
| **Budget Categories** | 3 categories | Basic needs only |
| **Savings Goals** | 1 goal | Taste only, want more |
| **Bill Reminders** | 3 bills | Basic bills covered |
| **Investment Tracking** | ❌ Not included | Premium feature |
| **AI Chats (Web)** | 5/hari | 1-2 meaningful conversations |
| **Receipt OCR** | 5/month | AI teaser |
| **Export** | CSV only | Basic expectation |
| **Analytics** | Basic (no trends) | Show value, gate advanced |
| **Voice Input** | ✅ Included | Core differentiator |
| **Offline Mode** | ✅ Included | Essential feature |
| **Telegram Bot** | ❌ Not included | **Paid feature** |
| **Ads** | ✅ Minimal | Monetize + annoyance drives upgrade |

#### User Journey (Free Tier)

```
Week 1-2: "Wah enak nih app!" (build habit)
  ├── Catat 3-5 transaksi/hari
  ├── Explore fitur basic
  └── AI chat 2-3x (coba capability)

Week 3: "Oh tinggal 20 transaksi lagi" (awareness)
  ├── Notice limit approaching
  ├── Consider upgrade
  └── Evaluate value

Week 4: "LIMIT REACHED! Upgrade sekarang!" (conversion trigger)
  ├── Hit 100 transactions
  ├── See upgrade prompt
  └── Make decision
```

#### Why These Limits Work

```
✅ 100 TRANSACTIONS = PERFECT HOOK PERIOD
   - Week 1-2: Build habit (70 transactions)
   - Week 3: Awareness (25 transactions)
   - Week 4: Limit reached (5 transactions)
   - Result: User dependent on app, ready to upgrade

✅ 5 AI CHATS/DAY = MEANINGFUL BUT NOT ENOUGH
   - Enough for 1-2 conversations
   - User experiences AI value
   - Heavy users will want more → upgrade

✅ CSV EXPORT FREE = BASIC EXPECTATION
   - Users expect to export their data
   - Not a "premium" feature
   - Excel/PDF still gated (professional formats)

✅ NO TELEGRAM BOT = CLEAR UPGRADE INCENTIVE
   - Bot costs money to run (server, API)
   - Paid users subsidize free users
   - Strong differentiation: Pro vs Sultan
```

async function handleMessage(ctx: Context) {
  const user = await getUser(ctx.from.id);
  
  if (!user || user.tier === 'starter') {
    await ctx.reply(
      '❌ Fitur Telegram bot hanya untuk tier PRO dan SULTAN.\n\n' +
      'Upgrade ke PRO untuk:\n' +
      '✅ Add transaksi via /add\n' +
      '✅ Cek saldo via /balance\n' +
      '✅ Notif budget otomatis\n\n' +
      'Upgrade: /upgrade'
    );
    return;
  }
  
  if (user.tier === 'pro') {
    // Command-based only
    if (!isCommand(ctx.message)) {
      await ctx.reply(
        '❓ Format tidak dikenali. Gunakan command:\n' +
        '/add <amount> <category> <desc>\n\n' +
        '💡 Mau chat natural? Upgrade ke SULTAN!\n' +
        '/upgrade_sultan'
      );
      return;
    }
    await handleCommand(ctx);
    return;
  }
  
  if (user.tier === 'sultan') {
    // Full AI conversation
    await handleAIConversation(ctx);
    return;
  }
}

## 10. RISK ANALYSIS

### Risk 1: Free Tier "Too Generous"

**Concern:** Users stay on free tier forever

**Probability:** MEDIUM (40%)

**Mitigation:**
- 100 transactions = user WILL hit limit in 3-4 weeks
- 1 goal = user WILL want more (aspirational)
- 5 AI chats = user WILL want more conversations
- No Telegram bot = clear upgrade incentive
- Ads on free tier (annoyance drives upgrade)

**Expected Conversion:** 12-15% (industry: 5-7%)

---

### Risk 2: Pro Tier Cannibalizes Sultan

**Concern:** Everyone picks Pro, nobody picks Sultan

**Probability:** LOW (20%)

**Mitigation:**
- Clear differentiation (conversational AI only in Sultan)
- Target Sultan at specific use cases (investors, business owners)
- Premium-only features that matter (real-time sync, tax reports)
- Status signaling (Sultan badge, early access)

**Expected Sultan Adoption:** 5-8% of paid users

---

### Risk 3: Price Too Low, Leaving Money on Table

**Concern:** Rp 29K-49K terlalu murah

**Probability:** LOW (15%)

**Counter-Argument:**
```
✅ LOWER PRICE = HIGHER VOLUME
   - Rp 29K = impulse buy (10K users @ Rp 29K = Rp 290M)
   - Rp 99K = consideration (1K users @ Rp 99K = Rp 99M)
   - Volume game > margin game for Indonesia

✅ ROOM TO INCREASE LATER
   - Start low to gain market share
   - Increase price AFTER achieving scale
   - Add premium tiers (Business, Enterprise)

✅ COMPETITIVE MOAT
   - Undercut competitors by 40-60%
   - Become "affordable alternative"
   - Build switching costs (data, habits)
```

---

### Risk 4: Telegram Bot Infrastructure Cost

**Concern:** Bot running cost太高

**Probability:** LOW (10%)

**Mitigation:**
- Free users don't access bot (no cost)
- Pro users: command-based (lightweight, low cost)
- Sultan users: AI-powered (higher cost, but higher margin)
- Overall sustainable business model
