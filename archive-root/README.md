# Archive Root

Folder ini menampung file root lama yang masih ingin disimpan, tetapi tidak layak tetap memenuhi root repo.

Isi folder ini saat ini terbagi dua jenis:

- dokumen lama, review, dan catatan implementasi yang bukan entrypoint dokumentasi utama
- script ad-hoc lama yang sudah tergantikan oleh versi yang lebih aman atau lebih rapi di `scripts/`

Aturan pakai:

- jangan jadikan folder ini sebagai tempat menambah file operasional baru
- kalau ada file di sini yang kembali dibutuhkan, pindahkan ke lokasi domain yang tepat
- kalau file sudah benar-benar tidak relevan, hapus dari folder ini di cleanup berikutnya

File yang tetap menjadi sumber dokumentasi aktif ada di:

- `README.md`
- `docs/`

Script operasional aktif tetap ada di:

- `scripts/`
